# @defdone/annon-mcp

## 0.1.0-beta.0

First public beta.

- Local stdio MCP server with `annon_buy`, `annon_status`, `annon_open`, `annon_recover`,
  `annon_verify`, `annon_sell` and `annon_budget`.
- Owner-set policy that tool calls cannot change: trusted contract, price cap, daily budget, allowed
  resources and a working directory for every file path.

### Dependencies

- `@defdone/annon` 0.1.0-beta.0
