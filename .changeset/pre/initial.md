Initial private workspace release of Annon:

- SDK and CLI for streaming PAY2 encryption, verified purchases over NEAR, Base and 1Click,
  grant downloads, recovery, per-file purchase storage budgets and protocol fees.
- MCP tools for selling, buying, opening, verifying, recovery, purchase status and storage budgets.
- Relayer for register, unlock, claim_key, reopen, reopen_seller, stop_sales and fund_file_storage,
  with admission limits and an optional durable settlement keeper.
- Demo host for x402 offers, purchase grant downloads, CORS and an optional Base facilitator.
